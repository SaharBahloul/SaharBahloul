### 💳 3. End-to-End Credit Default Prediction

🔗 **[View GitHub Repository](https://github.com/SaharBahloul/End-to-End-Credit-Default-Prediction-with-Data-Analytics-and-ML)**

Built an end-to-end Machine Learning pipeline to predict credit default risk using the **Home Credit dataset**.

**Key Features:**
- Exploratory Data Analysis (EDA) and feature engineering.
- Data preprocessing and class imbalance handling with SMOTE.
- Comparison of Random Forest, XGBoost, LightGBM, and CatBoost.
- Model evaluation and decision threshold optimization.
- Deployment of a Streamlit application for real-time credit risk scoring.

**Tech Stack:** `Python` `scikit-learn` `XGBoost` `LightGBM` `CatBoost` `SMOTE` `Streamlit`
